# Personal Designs ✦

A tiny, dependency-free home for design experiments and visual practice.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy to Vercel

Import this repository into Vercel. No build command or framework preset is required. The project is a plain static site, so Vercel can deploy it as-is.
